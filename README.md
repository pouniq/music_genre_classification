# پروژه پیشبینی ژانر موسیقی

پروژه تشخیص ژانر موسیقی به روش یادگیری ماشین با استفاده از دیتابیس GTZAN و کتابخانه librosa.




## خلاصه
- بهترین مدل: HistGradientBoosting
- هدف: تشخصیص ژانر موسیقی ها جدید

## دیتابیس موسیقی
استفاده از دیتاست GTZAN که در ۱۰ سبک موسیقی 
- hiphop
- rock
- blues
- reggea
- pop
- metal
- jazz
- disco
- country
- classical

  دسته بندی شده است.

  هر سبک موسیقی دارای ۱۰۰ نمونه ۳۰ ثانیه ای می باشد.


  ### تبدیل آن به دیتاست
  
  برای اینکه این دیتابیس موسیقی تبدیل به یک نوع داده برای انجام الگوریتم های یادگیری ماشین (سنتی) شود نیاز داشتیم
   که از یک کتابخانه در پایتون کمک بگیریم که اینکار را برای ما ساده تر کند.

  

### کارهایی که نیاز هست انجام بدم
- انجام EDA برای درک بهتر دیتا
- توضیح ساختاری و توضیح اینکه فرمول ها و شناس ها صدای چگونه کار می کنند و فرق آنها در سبک های مختلف رو نشون بده
- افزایش و بیشتر کردن داده های ترین با موزیک های مدرن تر
- یادگیری transfer learning
